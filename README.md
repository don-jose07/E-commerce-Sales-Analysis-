# E-commerce Sales Data Analysis

This repository contains a Python-based data analysis project focusing on an e-commerce sales dataset. The analysis is performed using the `pandas` library in a Google Colab Notebook, covering various aspects of sales performance.

## Project Overview

The main objective of this project is to explore and understand the e-commerce sales data to identify key trends, top-performing areas, and insights into customer behavior. The analysis includes:

- **Data Loading and Inspection**: Loading the `sales.csv` dataset into a Pandas DataFrame and inspecting its structure.
- **Sales by Category**: Analyzing total sales for different product categories to identify best-selling product types.
- **Sales by City**: Examining sales distribution across various cities to understand geographical performance.
- **Sales by Product**: Identifying individual products that generate the most revenue.
- **Sales by Payment Method**: Understanding the popularity and contribution of different payment methods to overall sales.
- **Overall Sales Statistics**: Calculating key metrics such as total sales, total quantity sold, number of orders, average sales per order, highest, and lowest single sales.
- **High-Value Order Identification**: Filtering and sorting orders to highlight significant transactions

## Observations and Insights

The notebook provides several meaningful observations based on the analysis, such as:

- Identification of top-performing product categories.
- Key geographical markets contributing most to sales.
- Popular individual products.
- Preferred customer payment methods.
- Overall sales performance metrics.
